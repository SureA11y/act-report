# SureA11y — ACT implementation report

The W3C ACT implementation reports for the [SureA11y accessibility engine](https://github.com/SureA11y/core),
expressed as EARL in JSON-LD. There are two, one per way the engine is run:

| Report | URL | Describes |
|---|---|---|
| SureA11y | <https://surea11y.github.io/act-report/act-report.jsonld> | the engine in jsdom, as `@surea11y/test-matchers`, the CLI and core on a DOM you supply run it |
| SureA11y in a browser | <https://surea11y.github.io/act-report/act-report-browser.jsonld> | the engine in Chromium, as the Playwright, Puppeteer, Selenium, WebdriverIO and Cypress bindings run it |

jsdom runs no page script, loads no linked style sheet or frame document and
lays nothing out, so some test cases can only be decided in a browser; the two
reports differ on those.

W3C re-downloads each URL daily, so a listing stays current without any action
here. The paths are stable and will not move; if one is ever relocated the old
path redirects. The browser report is published from the first engine release
that can scan in a browser.

## How it is produced

Both reports are generated by `scripts/act-report.js` in the engine repository,
the browser one with `--runner=chromium`,
run against the tag of the latest version on npm rather than a working tree, so
a third party can reproduce it from the same inputs. A workflow here
regenerates them every Monday against the live ACT test cases, so a new release
reaches the reports within a week; it can also be run by hand from the Actions
tab. A run that finds a false positive in either fails and leaves both
published reports as they were.

The test cases are W3C's, the ones its implementation listing scores reports
against, read from the corpus W3C publishes with its ACT rules; the Community
Group's site at act-rules.github.io carries some rules in an older version and
keeps two W3C has deprecated. Engine releases up to 1.11.1 generated the report
against the Community Group's corpus instead.

Each report records the engine's outcome for every applicable ACT test case,
including `passed` and `inapplicable` results, so "checked and found nothing"
is distinguishable from "does not implement this rule".

Listing on the W3C implementations page is not endorsement, and W3C does not
verify the data.
