# SureA11y — ACT implementation report

The W3C ACT implementation report for the [SureA11y accessibility engine](https://github.com/SureA11y/core),
expressed as EARL in JSON-LD.

**Report URL:** <https://surea11y.github.io/act-report/act-report.jsonld>

W3C re-downloads that URL daily, so the listing stays current without any
action here. The path is stable and will not move; if it is ever relocated the
old path redirects.

## How it is produced

The report is generated by `scripts/act-report.mjs` in the engine repository,
run against a released tag rather than a working tree, so a third party can
reproduce it from the same inputs. Each release regenerates it.

The report records the engine's outcome for every applicable ACT test case,
including `passed` and `inapplicable` results, so "checked and found nothing"
is distinguishable from "does not implement this rule".

Listing on the W3C implementations page is not endorsement, and W3C does not
verify the data.
