SureA11y — ACT implementation report

This repository hosts the W3C ACT implementation report for the SureA11y accessibility engine, expressed as EARL in JSON-LD.

The report

act-report.jsonld

W3C re-downloads this URL daily. The path is stable and will not move.

How it is produced

The report is generated against a released tag of the engine rather than a working tree, so it can be reproduced from the same inputs. Every release regenerates it. Outcomes are recorded for each applicable ACT test case, including passes and inapplicable cases.

Listing on the W3C implementations page is not endorsement, and W3C does not verify the data.
